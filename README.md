# PICO Artifact

This repository contains the artifact for **Transitive, Abstract, and Class
Polymorphic Immutability**. The package includes the PICO implementation,
benchmarks, annotated JDK case study, Rocq formalization, evaluation scripts,
and expected results. No additional repositories are required.

## Artifact evaluation

Start with the **[Artifact Evaluation Guide](Artifact-Evaluation.md)**. It
explains how to select a Docker image and run the kick-the-tires and complete
evaluations.

Detailed instructions for the two evaluation tracks are available separately:

- [PICO Checker Framework evaluation](Artifact-Evaluation-Checker.md)
- [Rocq formalization evaluation](Artifact-Evaluation-Rocq.md)
